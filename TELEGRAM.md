# Игра «ПРО РЕСТАВРАЦИЮ» в Telegram

Бот: **@prorestavraziagame_bot**.

URL игры для BotFather:

```text
https://nakarandashe27.github.io/PROrestavrazia-mini-game/telegram.html
```

После настройки Main Mini App ссылка запуска:

```text
https://t.me/prorestavraziagame_bot?startapp
```

## Подключение владельцем бота

1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/mybots`, выберите `@prorestavraziagame_bot`.
2. Перейдите **Bot Settings → Configure Mini App → Enable Mini App** (Main Mini App). Укажите HTTPS-адрес игры выше.
3. Через `/setmenubutton` выберите этого же бота, задайте тот же URL и текст кнопки **Играть**. Так игра открывается и из профиля, и из меню чата.
4. Откройте прямую ссылку `?startapp` на телефоне. Проверьте движение и прыжок одновременно, «Назад» → паузу, возврат после сворачивания, поворот экрана и полевую остановку.

## Поведение приложения

Начиная с 3.6.2 укажите `telegram.html` и в Main Mini App, и в Menu Button. Этот небольшой загрузчик проверяет `version.json` без кэша и открывает игру с номером текущей версии в URL, сохраняя параметры Telegram. При недоступности файла версии используется одноразовый адрес загрузки. В уже открытое старое окно новый код внедрить невозможно: после изменения адреса полностью закройте его и откройте бота заново. Номер запущенной версии виден внизу заставки; там же есть «Обновить игру». Активная экспедиция автоматически не перезагружается.

Звук разблокируется непосредственно при нажатии и повторно после прерывания. Для поддерживаемых iPhone/WebView используется `navigator.audioSession.type = 'playback'` во время игры; при паузе или выключении звука сессия возвращается в `auto`. Если AudioContext заблокирован, появляется явная кнопка включения звука. Поведение API сверено с [WebKit](https://bugs.webkit.org/show_bug.cgi?id=237322) и [MDN AudioContext state](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/state). Браузерная эмуляция проверяет отклонённый `resume()`, восстановление после паузы и наличие сигнала; она не подтверждает слышимость на физическом iPhone в Telegram.

- Общая игра и тот же GitHub Pages: обновления `main` публикуются одновременно для сайта и Mini App.
- Официальный SDK загружается только при параметрах запуска Telegram или `?telegram=1`; обычный сайт и локальный `file:` от него не зависят. При ошибке загрузки остаётся обычная игра.
- Окно раскрывается, интерфейс учитывает устойчивую высоту и обе безопасные области Telegram. Поворот экрана разрешён. Полный экран включается кнопкой игрока в Telegram 8.0+.
- «Назад» открывает паузу в игре и закрывает вложенные экраны. Во время обязательного задания кнопка скрыта: его нельзя случайно пропустить с потерей детали. При сворачивании игра ставится на паузу.
- Жест сворачивания отключён только во время движения и интерактивных заданий. Выход с незавершённой экспедицией требует штатного подтверждения Telegram 6.2+.
- Прогресс находится в памяти текущего окна, как в веб-версии. Закрытие или перезагрузка начинает новую экспедицию; подтверждение не является автосохранением.
- Telegram ID, профиль и `initData` не используются. Если позднее появятся серверные результаты или учётные записи, потребуется серверная проверка `initData`.
- В Telegram PDF сохраняется через системное меню Web Share, если клиент поддерживает передачу файлов. В остальных клиентах предлагается экран для снимка сертификата. `downloadFile` Telegram требует публичный HTTPS-файл и не подходит для локально созданного персонального PDF. Обычный сайт сохраняет PDF как прежде; личное имя никуда не загружается.

## Проверка

```sh
npm ci
npm run build
npx playwright install chromium
npm run test:telegram
```

Для уже установленного Chrome можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE` абсолютным путём. По умолчанию используется Chromium Playwright. Тест запускает временный preview на `127.0.0.1:4178` и завершает его после проверки.

Тест подставляет контракт официального SDK, проверяет размеры 390×844, 320×568 и 844×390, переходы и паузу, изменение safe area/viewport, старый API, недоступный SDK, обычный сайт и офлайн-файл. Снимки сохраняются в игнорируемую папку `tests/telegram-artifacts`. Это автоматическая проверка интеграции; она не заменяет проверку настоящего клиента Telegram и настройки бота владельцем.

Основание API и настройки: [официальная документация Telegram Mini Apps](https://core.telegram.org/bots/webapps), разделы Initializing Mini Apps, Launching the main Mini App и Menu Button Mini Apps.
