# Архисбор · Живое наследие · Версия 3.4

Выставочная игра о реставрации: прогулка за буквами, короткие полевые исследования, подъём к деталям типографии Сытина, мастерские и именной сертификат. Сохранены фирменные AdvakenSans-Expanded, Inter Tight и палитра исходной игры. Исходники этой версии находятся в корне репозитория; прежние прототипы сюда не входят.

Правила и основания решений — в [DESIGN-NOTES.md](DESIGN-NOTES.md), источники архитектурного рисунка — в [FACADE-RESEARCH.md](FACADE-RESEARCH.md), подтверждённые проверки — в [QA.md](QA.md). Ход пяти циклов шлифовки описан в [POLISH-CYCLES.md](POLISH-CYCLES.md). `STYLE-REVIEW.md` сохраняет историю возвращения фирменного оформления.

## Перед путешествием

Компактная кнопка «Создать своего героя» находится возле текста заставки и открывает отдельный редактор на весь экран. Иллюстрация типографии остаётся свободной. В редакторе можно указать своё имя, выбрать один из безымянных пресетов «Образ 01»–«Образ 04» или настроить каску/кепку, цвет головного убора, куртку, брюки, тон кожи и волосы. Предпросмотр показывает покой и движение. Выбранный образ используется в самой игре; способности и физика у всех одинаковые.

Имя до 40 символов появляется на памятном сертификате. Пустое поле заменяется на «Юный реставратор». Выберите «Знакомство» — одно слово и три детали — или «Экспедицию» — три слова и шесть деталей. Можно сразу перейти к лесам. Время зависит от чтения, остановок и навыка управления; указанные на заставке минуты являются ориентиром.

На заставке доступны фиксированный день, ночь или постепенный переход «День → ночь». Кнопка звука находится в верхней панели. Редактор образа и эти настройки доступны также из паузы.

## Управление и исследование

- Стрелки ← → или A / D — движение.
- Пробел, ↑ или W — прыжок. Удержание даёт полную высоту.
- ↓ или S — спуск сквозь настил на следующий ярус.
- R — возврат на последнюю надёжную площадку.
- E или кнопка рядом со станцией — полевая остановка.
- Escape — пауза; повторное нажатие продолжает игру. В редакторе или полевой остановке Escape закрывает этот экран.
- На сенсорном экране доступны кнопки снизу; движение и прыжок можно нажимать одновременно.
- В реставрационной мастерской выберите фрагмент и подходящее место. Перетаскивание не требуется; доступны Tab и Enter.

На каждом этапе со словом есть три необязательные станции: проявить клеймо кирпича, совместить линейку с границей детали и настроить кадр для фотофиксации. Кисть принимает отдельные нажатия по участкам; ползунками можно управлять пальцем, мышью или стрелками клавиатуры. После завершения сохраните заметку — она появится в полевом журнале внутри альбома. Станцию можно пропустить или закрыть и продолжить основной путь. Эти остановки не требуются для получения сертификата.

Падение возвращает героя на последнюю площадку без потери находок и выполненных исследований. Ошибки в мастерских и полевых заданиях можно исправлять без штрафа. При потере фокуса игра ставится на паузу. В паузе можно включить помощь с прыжками или получить «Новую раскладку» текущего этапа.

## Что изменилось в 3.4

Персонализация вынесена в самостоятельный редактор. Готовые образы не подставляют чужое имя: имя участника и внешний вид независимы. Цвета меняются в предпросмотре и на игровом персонаже.

Три полевых действия дополняют движение между буквами. Они размещаются на уже доступных неподвижных опорах, не меняя основной маршрут. Герой реагирует короткими облачками на место, завершение исследования, возвращение после падения и наступление сумерек.

Новый seed создаётся локально через `crypto.getRandomValues`, с запасным вариантом при недоступности API. Нулевое значение и непосредственный повтор последнего seed исключены. Если хранилище браузера доступно, в нём сохраняется только последний seed для защиты от повторения при следующем открытии. Это не обещает бесконечно уникальных геометрий: для того же seed генерация остаётся воспроизводимой.

Музыкальный мотив сохранён. К нему добавлены редкие тихие движения кисти, деревянные касания и шелест, соответствующие месту. Реплики имеют короткий музыкальный сигнал, полевые задания — собственную обратную связь. В реставрационной мастерской звук сопровождает выбор фрагмента, правильное размещение и завершение. Всё синтезируется локально без записей, имитации речи и сетевых запросов.

## Финал и данные участника

Финал показывает сравнение игрового фасада, альбом и именной сертификат. Сертификат можно раскрыть для фотографии экрана или скачать настоящим одностраничным PDF A4 в альбомной ориентации. Экран и файл используют одну композицию 1680×1188, отрисованную в 2520×1782. В PDF помещается изображение: кириллица и фирменные буквы сохраняются, выделяемого текстового слоя нет.

Имя, образ, настройки и прогресс находятся в памяти открытой страницы и сбрасываются при перезагрузке. Образ и настройки сохраняются при возвращении в редактор и новых поездках внутри страницы. Кнопка «Новое путешествие» в финале очищает имя. Имя не отправляется на сервер и не записывается в localStorage. Скачанный по желанию участника PDF, конечно, содержит указанное имя.

## Разработка

Нужны Node.js 22 не ниже 22.12 и npm. Выполняйте команды из корня репозитория:

```sh
npm ci
npm run dev
```

Локальный адрес: `http://127.0.0.1:4173`. Сборка проверяет TypeScript и создаёт автономный комплект в `dist`. Интерфейс и задания сделаны в React/DOM, игровой мир — в Canvas 2D, звук — в Web Audio.

В игре нет внешних загрузок шрифтов, CDN, аналитики, запросов к ИИ или игрового сервера. Интернет нужен только для открываемых пользователем ссылок на источники. В разработке `window.__game` и `window.__audioStatus` служат для воспроизводимых проверок; эти диагностические ссылки не должны попадать в production.

## Проверки и автоматическая публикация

[`.github/workflows/pages.yml`](.github/workflows/pages.yml) запускается при push в `main`. На Node.js 22 он устанавливает зависимости из lock-файла, выполняет переносимые проверки, собирает проект и публикует содержимое `dist` в GitHub Pages. При ошибке проверки или сборки новая версия не развёртывается.

Те же команды можно выполнить локально:

```sh
npm ci
npm test
node tests/fieldwork-checks.mjs
npm run build
```

`npm test` проверяет физическую проходимость 400 маршрутов, генерацию и 64 узких фасадных маршрута. Полевой набор проверяет 900 этапов, 2700 станций, 30 физических прохождений с 90 взаимодействиями и отказоустойчивость нового seed. Проверки используют настоящий Engine с обычными командами движения, а браузер для них не требуется. Состав и ограничения подробно описаны в [tests/README.md](tests/README.md).

В репозитории находятся только переносимые исходники этих тестов. Браузерные сценарии `v6-*`, старые `v5-*`, аудиопрогоны, PNG, PDF, видео и архивы из локальной истории QA сюда не включены. Упоминания таких файлов в [QA.md](QA.md) и [POLISH-CYCLES.md](POLISH-CYCLES.md) описывают выполненные локальные проверки; GitHub Actions их не воспроизводит. Успешные CI-тесты подтверждают свою область покрытия и не заменяют визуальный просмотр или проверку игры с посетителями.
